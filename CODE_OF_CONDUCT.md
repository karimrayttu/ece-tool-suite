# Code of conduct

This project is small, so this is short.

Be civil in issues, pull requests and discussions. Disagree about the engineering as much as
you like; do not make it about the person. Harassment, personal attacks, and unsolicited
sexual or discriminatory remarks are not welcome here, and neither is deliberately wasting
other people's time.

Technical disagreements get resolved with evidence. If you think a measurement, a datasheet
value or a design decision is wrong, cite the source. "This is obviously wrong" is not an
argument, and neither is a reference to your seniority.

If someone's behaviour is a problem, report it privately through
[GitHub's report abuse form](https://github.com/contact/report-abuse), or open a private
security advisory if you would rather reach me directly. I read these.

I moderate this repository. That means I can edit, hide, or delete comments, close issues and
pull requests, and block accounts. I will say why when I do, unless saying why would make
things worse for the person who reported it.
